# VH3rd-Remastered-Rebalanced

This configuration package is a Rebalance of the Vault Hunters 3rd Ed - Remastered Modpack.

The tuned configuration files target the v2.0.4 build and I'll be working on an update for the newly released v3.0.0 build.

## Loot Balance Changes

Listed below are the major rebalance changes where an item's expected drop rate has changed ±10% or more. This accounts for both how frequently an item is selected and the quantity received when it drops. Items with smaller changes are not listed, as their expected drop rates remain mostly the same as the stock modpack. Vault Hunters uses a weighted loot system, so increasing the drop weight of one item can reduce the chances of other items in the same loot pool. I've tried to avoid that as much as possible, though some reductions are intentional. For changes of ±50% or more, I've also listed the approximate chance of the item appearing in a chest to provide additional context.

### Wooden Chests Loot
- Drift Wood: +15% increase drop chance
- Vault Plating: +25% increase drop chance
- Magic Silk: +20% increase drop chance
- Carbon Nugget: +20% increase drop chance
- Shulker Shell: -35% decrease drop chance
- Wooden Chest Scroll: -72% decrease drop chance (Drop chance is about ~0.75%)
- Mod Box: +38% increase drop chance

### Wooden Barrel (Level 50+ ~0.78% chance, or about ~1 in 128 Wooden Chests can spawn as a Wooden Barrel)

These are very rare Wooden Barrels that spawn after level 50, with a increased chance of containing some of the rarer Wooden Chest items along with a few extras!  Below are all the items that can drop from a Wooden Barrel.

- Chromatic Iron Ingots
- Carbon Nuggets
- Vault Plating
- Mod Boxes
- Vault Catalyst Fragments
- Silver Scrap
- Vault Essence
- Wooden Chest Scrolls
- Chromatic Steel Ingots
